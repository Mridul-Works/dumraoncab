4. ADMIN PANEL (/admin — noindex, password-protected)
---------------------------------------------------------------------
- Login with password (ADMIN_PASSWORD env; httpOnly SHA-256 cookie,
  30-day session; logout button)
- Stats tiles: total website bookings, awaiting confirmation,
  received today, travelling today
- Bookings table: newest first — received time, customer (name +
  clickable phone), trip, travel date, car, source (widget/form),
  status dropdown (new / confirmed / completed / cancelled) saved
  via PATCH; empty-state explains what appears here
- Fleet table with photo thumbnails, category, seats, specs, rate
- Routes table and published fares (per-km + hourly packages)
- Content overview: services / testimonials / FAQ counts + all
  contact channels
- Pointer to lib/site.ts as the single place content is edited

5. API (Node runtime; data in data/bookings.json — gitignored)
---------------------------------------------------------------------
POST  /api/bookings        public — save a booking request
GET   /api/bookings        admin — list all bookings
PATCH /api/bookings/[id]   admin — update booking status
POST  /api/admin/login     set admin cookie; DELETE — logout
NOTE: JSON-file storage suits a VPS/Node host. On serverless
(Vercel etc.) swap lib/store.ts for a database first.
